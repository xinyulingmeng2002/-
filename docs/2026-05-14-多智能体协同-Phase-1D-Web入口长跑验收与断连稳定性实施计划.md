# Phase 1D Web 入口长跑验收与断连稳定性实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:systematic-debugging when a runtime issue is found, and use superpowers:verification-before-completion before recording completion.

**Goal:** 通过真实 dev server + Vite Web 入口验证外部 Agent 接入链路，并修复验收中发现的 adapter 断连稳定性问题。

**Architecture:** 不新增协议，不改变房间/Agent 权限模型。验收路径使用真实 `dev:server`、真实 `@ma/web` Vite 入口、真实 Generic adapter CLI，并通过 Vite `/api` 代理完成 invite、消息、附件、watch 与 bridge session 诊断。

**Tech Stack:** Fastify server, Vite, Generic bridge CLI, Vitest, TypeScript.

- [x] 先给 Generic runtime 增加失败测试。
