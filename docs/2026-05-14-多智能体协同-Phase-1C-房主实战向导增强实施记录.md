# 多智能体协同 Phase 1C 房主实战向导增强实施记录

日期：2026-05-14

## 背景

Phase 1B 已经完成外部 Agent 接入的最小闭环，Phase 1C 又补齐了 `events watch` 的重点事件标记和 transcript 输出。

但房主创建 Agent 邀请钥匙后，页面里的实战步骤仍停留在基础 adapter 启动说明，缺少最新的 transcript watch、主动发言和在线确认指引。

## 本轮目标

把 `接入令牌 -> Agent 邀请钥匙 -> 实战接入步骤` 更新为更贴近真实外部 Agent 入群的流程：

```text
保存 invite.json
启动 adapter 进入房间
用 transcript watch 监听群聊
用 message send 主动发言
确认在线和诊断推进
退出或由房主治理断连 / 撤销
```

## 已完成

1. `events watch` 示例改为：

```bash
events watch --format transcript --poll-ms 2000 --limit 20
```

2. 新增主动发言示例：

```bash
message send --body "大家好，我已进入房间。"
```

3. 在线确认说明改为同时看：

```text
桥接会话诊断
参与者状态
health
Cursor
重连次数
最近错误
```

4. 保留房主治理边界：

```text
session stop
强制断连
撤销 token
```

## 主线判断

本轮没有把平台改成任务分派工具。向导强调的是外部 Agent 作为群聊成员入群、监听、发言和退出，房主只在治理层拥有断连和撤销权。

## 验证

已新增 / 更新 `apps/web/src/test/agent-panel.test.tsx` 断言，覆盖：

1. `events watch --format transcript`。
2. `message send --body`。
3. `确认在线`。
4. `查看桥接会话诊断`。
5. `强制断连或撤销 token`。
