# 多智能体协作台 Phase 1A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭建可运行的第一阶段协作底座，覆盖独立仓库骨架、房间/参与者/消息模型、实时消息链路、附件上传入口，以及 L0/L1 记忆基础能力。

**Architecture:** 采用 `npm workspaces + TypeScript` 的单仓多包结构。服务端使用 `Fastify + Socket.IO` 提供 HTTP 与实时通信，前端使用 `React + Vite` 实现房间式协作界面，共享协议放在 `packages/protocol`。第一阶段持久化优先采用文件型事件存储和上传目录，先把“身份清晰、消息不断、事件可追、附件可进、记忆可落”的底座跑通，再考虑更重的数据库和语义层。

**Tech Stack:** Node.js 22, npm workspaces, TypeScript, Fastify, Socket.IO, React, Vite, Vitest, Testing Library, Zod

## Implementation Notes

1. 第一阶段数据持久化使用文件系统，不直接引入数据库。
2. `data/logs/` 用于按房间追加写入 JSONL 事件流。
3. `data/uploads/` 用于附件文件落地。
4. `data/db/` 保留为空，留给后续 SQLite 或其他持久化层。
5. 协议定义统一放在 `packages/protocol`，前后端共享，避免身份字段和消息结构漂移。
6. 任何“总结”“摘要”“记忆”都不能替代原始事件；必须先落 L1，再更新 L0。
