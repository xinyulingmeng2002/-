当前已完成准真实 CLI 接入验收和 Phase 1D Generic longrun smoke。

```bash

npm run smoke:phase1d:longrun
```

```text

```

原因：当前沙箱默认不允许监听 `127.0.0.1`。

提升权限后运行结果：

```text
phase1b generic cli smoke passed
phase1d generic longrun smoke passed
```

## 覆盖能力

`smoke:phase1b:cli` 使用真实 Generic bridge CLI 与临时本地 HTTP 服务，覆盖：

1. 生成并读取 Agent 邀请钥匙 invite 文件。
2. `session start --invite-file <invite.json>`。
3. 持久化 session 文件。
4. `message send` 通过 bridge ingress 发言。
5. `workspace snapshot` 通过 bridge egress 读取房间工作快照。
6. `events pull` 通过 bridge egress 拉取房间事件。
7. 脚本结束时停止 session start 进程并清理临时资源。

`smoke:phase1d:longrun` 进一步覆盖：

1. 真实 Generic bridge CLI session 长运行。
2. `events watch --format json` 长监听。
3. 结构化 `mentions` 触发 `attentionTags: ["mentioned-you"]`。
4. 结构化 `replyToMessageId` 在同批次可定位原消息时触发 `attentionTags: ["reply-to-you"]`。
5. 附件消息进入 watch 事件批次。
6. session 文件仍保持有效 agent / room / session 上下文。

## 未覆盖能力

该 CLI smoke 不覆盖真实浏览器人工路径：

1. 房主在 Web 页面点击创建 token。
2. 人工复制 invite JSON。
3. 人工启动 `events watch --format transcript` 并观察终端输出。
4. Web 页面人工 `@Generic Agent` 后 watch transcript 输出 `mentioned-you`。
5. Web 页面人工回复 Generic Agent 后 watch transcript 输出 `reply-to-you`。
6. Web 页面上传附件并人工查看缩略图/原图。
7. 房主在页面中强制断连或撤销 token。

## 阶段判断

该 smoke 足以支撑“工程侧进入 Phase 1D”的判断，因为 Phase 1D 的主题正是继续增强真实长期运行、可观测性和接入稳定性。

不建议因为浏览器人工长跑尚未执行而继续在 Phase 1C 追加功能。更合理的做法是进入 Phase 1D 后，把浏览器人工长跑作为 1D-P0 产品侧确认任务。
